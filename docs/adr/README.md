# Architecture Decision Records (ADRs)

Esta pasta contém os registros de decisões arquiteturais (ADRs) do `kibble-api`.

## Convenções

- Um arquivo por decisão: `NNNN-titulo-em-kebab-case.md` (ex.: `0001-usar-postgresql.md`).
- A numeração é sequencial e nunca reutilizada.
- ADRs são imutáveis após aceitos. Para mudar uma decisão, crie um novo ADR e marque o antigo como `Superseded by ADR-NNNN`.
- Use o template em [`template.md`](./template.md).

## Status possíveis

`Proposed` · `Accepted` · `Deprecated` · `Superseded`
